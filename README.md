# Proyecto_Reciclaje_Comunitario
# Aplicación web para la gestión de residuos y reciclaje comunitario

Proyecto del curso SC-502, Escuela de Ingeniería en Sistemas de Computación, Universidad Fidélitas.

Aplicación web que permite a los usuarios registrar sus entregas de material reciclable, acumular puntos y canjearlos por recompensas en comercios locales afiliados. También ofrece herramientas a los centros de acopio y a los administradores. Se desarrolló aplicando la metodología Design Thinking.

## Tecnologías

HTML5, CSS3, JavaScript, PHP y MySQL (en esta entrega: Front End).

## Estructura del proyecto

- `index.html`: página de inicio
- `pages/`: una página HTML por pantalla
- `css/`: estilos (global y por módulo)
- `js/`: scripts (componentes, validaciones y por módulo)
- `assets/img/`: imágenes y logos

## Cómo abrir el proyecto

1. Clonar el repositorio: `git clone https://github.com/mjmt123/Proyecto_Reciclaje_Comunitario.git`
2. Abrir la carpeta en el editor de código.
3. Abrir `index.html` en el navegador.

## Forma de trabajo

- Una rama por módulo: `feature/usuarios`, `feature/reciclaje`, `feature/centros`, `feature/admin`.
- No se sube directo a `main`: se abre un Pull Request y otra persona del equipo lo revisa.
- Commits pequeños, con mensajes claros.
